02 / CONCEPT

What is cloud
computing?

Cloud computing provides access to computing resources over the Internet.

Instead of buying and maintaining all the hardware myself, I can use servers, storage, networking, and software provided by a cloud service. These resources run in the provider's data centres and can be accessed when needed. The amount of capacity can change with the workload, although the available options and costs depend on the service.

Hosting this website is a simple example. On my laptop, the HTML, CSS, and image files are only available locally. After I upload them to a hosting platform, a web server delivers those files to visitors through a public URL. My laptop does not need to stay on for the website to remain available. The provider operates the hosting infrastructure, while I remain responsible for the content, file paths, and repository access. Using cloud services still requires attention to security, usage limits, and possible charges.

03 / SERVICE MODELS

Cloud services

The main difference is how much
the provider manages for you.

01

IaaS

Infrastructure as a Service

Provides infrastructure such as virtual machines, storage, and networks. The customer manages the operating system, installed software, and applications.

Customer manages
Operating system and applications
Example
Amazon EC2
02

PaaS

Platform as a Service

Provides a managed environment for deploying applications. The provider operates the infrastructure and runtime, while the customer focuses on application code and data.

Customer manages
Application code and data
Example
Google App Engine
03

SaaS

Software as a Service

Provides a complete application over the Internet. The provider maintains the software and infrastructure, while the customer uses the features and manages account settings.

Customer manages
Account settings and content
Example
Gmail
